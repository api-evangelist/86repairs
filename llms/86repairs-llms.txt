# 86 Repairs

> Restaurant equipment repair and maintenance (R&M) management platform, founded 2018 in Chicago
> and acquired by OEM foodservice parts distributor Parts Town in June 2026. 86 Repairs manages the
> repair lifecycle for restaurant operators — 24/7 intake and troubleshooting, warranty
> verification, dispatch to a vetted service-provider network, preventative maintenance scheduling,
> equipment and asset inventory, invoice assurance and R&M spend analytics. It is delivered as an
> end-user web portal and mobile apps.
>
> 86 Repairs publishes NO public API. There is no developer portal, no API reference, no
> OpenAPI/AsyncAPI/GraphQL contract, no SDK on any public registry, no documented webhooks, no MCP
> server and no A2A agent card on any host it controls. This file is generated by API Evangelist
> from public sources; it is not published by 86 Repairs.
